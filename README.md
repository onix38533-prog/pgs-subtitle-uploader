# PGS Subtitle Uploader (MVP)

لوحة خاصة لرفع ملفات `.sup` (PGS) وربطها بأفلام ومسلسلات عبر IMDb ID، مع endpoint متوافق مبدئياً مع مورد subtitles في Stremio.

## تنبيه توافق مهم
توثيق Stremio يعرّف كائن الترجمة عبر `url`, `lang`, و`id`، لكنه لا يذكر `.sup` أو PGS كصيغة مدعومة صراحةً. لذلك هذا المشروع يخزّن الملف الأصلي ويقدمه كما هو، لكن نجاح عرضه داخل مشغّل Stremio غير مضمون ويجب اختباره على جهازك قبل اعتبار المشروع مكتملاً. لا يوجد تحويل إلى SRT/VTT.

## تشغيل محلي للتجربة
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. عيّن `ADMIN_PASSWORD` إلى كلمة مرور طويلة و`ADDON_KEY` إلى مفتاح عشوائي طويل (24 حرفاً على الأقل).
4. ثبّت الاعتماديات: `npm install`
5. شغّل: `npm start`
6. افتح `http://localhost:3000` وسجّل الدخول ببيانات ADMIN_USER وADMIN_PASSWORD.

## النشر على الإنترنت
يوجد `Dockerfile` و`render.yaml` كقالب نشر على Render. أنشئ خدمة Web من هذا المستودع، وأضف قرصاً دائماً مركباً على `/app/data`. اضبط:
- `ADMIN_USER`
- `ADMIN_PASSWORD`
- `ADDON_KEY`
- `BASE_URL` (رابط HTTPS النهائي للخدمة)
- `DATA_DIR=/app/data`

لا تستخدم تخزيناً مؤقتاً ephemeral للملفات؛ ستفقد الترجمات عند إعادة تشغيل الخدمة. احتفظ بنسخة احتياطية من مجلد `data`.

## تثبيت الإضافة في Stremio
بعد النشر، يكون رابط manifest:
`https://YOUR-HOST/addon/YOUR_ADDON_KEY/manifest.json`

أضف الرابط من قسم Addons في Stremio. لا تنشر الرابط أو مفتاح الإضافة علناً.

## ملاحظات إصدار MVP
- واجهة الإدارة محمية بـ HTTP Basic Auth.
- ملفات SUP فقط، حد الرفع الافتراضي 300MB.
- الأفلام: تطابق IMDb ID.
- المسلسلات: تطابق IMDb ID + الموسم + الحلقة. يقرأ endpoint قيم `season` و`episode` أو `videoSeason` و`videoEpisode` من query string؛ قد يلزم ضبط طريقة استخراج بيانات الحلقة بعد اختبار طلبات Stremio الفعلية على إصدارك.
- قاعدة البيانات JSON مناسبة للنموذج الأولي وحساب شخصي محدود. لا تستخدم عدة نسخ متوازية من الخدمة دون نقل قاعدة البيانات إلى تخزين مشترك.
- غيّر كلمات المرور والمفاتيح قبل النشر.
